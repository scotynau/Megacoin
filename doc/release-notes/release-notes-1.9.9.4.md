Megacoin Core version 1.9.9.4 is now available from:

  <https://megacoin-mec.cc>

This release provides updated hardcoded chain checkpoints and block validation improvements.

Features & Changes
------------------
- **Checkpoints Update**: Added recent historical block headers as hardcoded chain checkpoints.
- **Validation Routines**: Refactored transaction script evaluation speed during IBD (Initial Block Download).
- **Masternode Sync**: Improved initial synchronization sequence for Masternode list and winner payment states.
