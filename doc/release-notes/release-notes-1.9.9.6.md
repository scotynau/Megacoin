Megacoin Core version 1.9.9.6 is now available from:

  <https://megacoin-mec.cc>

This release contains critical stability fixes, updated checkpoints, and network peer management improvements.

Features & Changes
------------------
- **Chain Checkpoints**: Updated chain checkpoints for faster initial block synchronization.
- **Masternode Network Stability**: Fixed race conditions during Masternode winner broadcast propagation.
- **Dependency Compatibility**: Improved compatibility with modern C++ build tools and Linux distributions.
