Megacoin Core version 1.9.9.3 is now available from:

  <https://megacoin-mec.cc>

This release completely removes the legacy Kimoto Gravity Well (KGW) difficulty algorithm in favor of Bitcore Diffshield.

Features & Changes
------------------
- **Kimoto Gravity Well Removal**: Fully removed legacy KGW calculation code to simplify consensus code paths.
- **Bitcore Diffshield Optimization**: Optimized Bitcore Diffshield parameter calculation and retargeting routines.
- **Code Cleanups**: Removed deprecated unused consensus structs and macros.
