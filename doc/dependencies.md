Dependencies
============

These are the dependencies currently used by Megacoin Core. You can find instructions for installing them in the `build-*.md` file for your platform.

| Dependency | Version used | Minimum required |
| --- | --- | --- |
| Berkeley DB | [4.8.30](http://www.oracle.com/technetwork/database/database-technologies/berkeleydb/downloads/index.html) | 4.8.x |
| Boost | [1.76.0](https://www.boost.org/users/download/) | 1.58.0 |
| Clang |  | 3.3+ (C++11 support) |
| GCC |  | 4.8+ / GCC 11-14 supported |
| libevent | [2.1.8-stable](https://github.com/libevent/libevent/releases) | 2.0.22 |
| MiniUPnPc | [2.0.20180203](http://miniupnp.free.fr/files) |  |
| OpenSSL | [1.0.1k / 1.1.1+](https://www.openssl.org/source) |  |
| protobuf | [2.6.1](https://github.com/google/protobuf/releases) |  |
| Python (tests) |  | 3.4+ |
| qrencode | [3.4.4](https://fukuchi.org/works/qrencode) |  |
| Qt | [5.9.6](https://download.qt.io/official_releases/qt/) | 5.x |
| ZeroMQ | [4.3.4](https://github.com/zeromq/libzmq/releases) | 4.x |
