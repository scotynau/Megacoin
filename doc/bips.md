BIPs Implemented in Megacoin Core
==============================

BIPs implemented by Megacoin Core (up-to-date for **v1.10.0** base):

* [`BIP 9`](https://github.com/bitcoin/bips/blob/master/bip-0009.mediawiki): Parallel soft-fork deployment support (used for SegWit and Masternode Payment Enforcement soft-fork).
* [`BIP 11`](https://github.com/bitcoin/bips/blob/master/bip-0011.mediawiki): Multisig standard outputs.
* [`BIP 13`](https://github.com/bitcoin/bips/blob/master/bip-0013.mediawiki): P2SH address format.
* [`BIP 14`](https://github.com/bitcoin/bips/blob/master/bip-0014.mediawiki): Subversion user agent strings.
* [`BIP 16`](https://github.com/bitcoin/bips/blob/master/bip-0016.mediawiki): Pay-To-Script-Hash (P2SH) evaluation.
* [`BIP 21`](https://github.com/bitcoin/bips/blob/master/bip-021.mediawiki): URI format (`megacoin:` scheme).
* [`BIP 22`](https://github.com/bitcoin/bips/blob/master/bip-0022.mediawiki): `getblocktemplate` (GBT) RPC protocol for mining.
* [`BIP 23`](https://github.com/bitcoin/bips/blob/master/bip-0023.mediawiki): GBT extensions including longpolling and block proposals.
* [`BIP 30`](https://github.com/bitcoin/bips/blob/master/bip-0030.mediawiki): Duplicate transaction ID avoidance rules.
* [`BIP 31`](https://github.com/bitcoin/bips/blob/master/bip-0031.mediawiki): `pong` protocol message.
* [`BIP 32`](https://github.com/bitcoin/bips/blob/master/bip-0032.mediawiki): Hierarchical Deterministic (HD) Wallets.
* [`BIP 34`](https://github.com/bitcoin/bips/blob/master/bip-0034.mediawiki): Block height in coinbase script.
* [`BIP 35`](https://github.com/bitcoin/bips/blob/master/bip-0035.mediawiki): `mempool` protocol message.
* [`BIP 37`](https://github.com/bitcoin/bips/blob/master/bip-0037.mediawiki): Bloom filtering and partial Merkle trees for SPV clients.
* [`BIP 42`](https://github.com/bitcoin/bips/blob/master/bip-0042.mediawiki): Infinite inflation bug fix (subsidy capping).
* [`BIP 61`](https://github.com/bitcoin/bips/blob/master/bip-0061.mediawiki): `reject` P2P protocol messages (configurable via `-enablebip61`).
* [`BIP 65`](https://github.com/bitcoin/bips/blob/master/bip-0065.mediawiki): `CHECKLOCKTIMEVERIFY` opcode.
* [`BIP 66`](https://github.com/bitcoin/bips/blob/master/bip-0066.mediawiki): Strict DER signature compliance.
* [`BIP 68`](https://github.com/bitcoin/bips/blob/master/bip-0068.mediawiki): Relative lock-time sequence locks.
* [`BIP 70`](https://github.com/bitcoin/bips/blob/master/bip-0070.mediawiki) [`71`](https://github.com/bitcoin/bips/blob/master/bip-0071.mediawiki) [`72`](https://github.com/bitcoin/bips/blob/master/bip-0072.mediawiki): Payment Protocol support in GUI.
* [`BIP 90`](https://github.com/bitcoin/bips/blob/master/bip-0090.mediawiki): Height-based activation triggering for soft forks.
* [`BIP 111`](https://github.com/bitcoin/bips/blob/master/bip-0111.mediawiki): `NODE_BLOOM` service bit signaling.
* [`BIP 112`](https://github.com/bitcoin/bips/blob/master/bip-0112.mediawiki): `CHECKSEQUENCEVERIFY` opcode (CSV).
* [`BIP 113`](https://github.com/bitcoin/bips/blob/master/bip-0113.mediawiki): Median time past lock-time calculations.
* [`BIP 125`](https://github.com/bitcoin/bips/blob/master/bip-0125.mediawiki): Opt-in Replace-By-Fee (RBF) signaling.
* [`BIP 130`](https://github.com/bitcoin/bips/blob/master/bip-0130.mediawiki): Direct headers announcement negotiation.
* [`BIP 133`](https://github.com/bitcoin/bips/blob/master/bip-0133.mediawiki): `feefilter` P2P protocol messages.
* [`BIP 141`](https://github.com/bitcoin/bips/blob/master/bip-0141.mediawiki): Segregated Witness consensus layer.
* [`BIP 143`](https://github.com/bitcoin/bips/blob/master/bip-0143.mediawiki): Transaction Signature Verification for Version 0 Witness Program.
* [`BIP 144`](https://github.com/bitcoin/bips/blob/master/bip-0144.mediawiki): Segregated Witness peer-to-peer network messages.
* [`BIP 145`](https://github.com/bitcoin/bips/blob/master/bip-0145.mediawiki): `getblocktemplate` updates for Segregated Witness.
* [`BIP 147`](https://github.com/bitcoin/bips/blob/master/bip-0147.mediawiki): `NULLDUMMY` softfork.
* [`BIP 152`](https://github.com/bitcoin/bips/blob/master/bip-0152.mediawiki): Compact block transfer protocol.
* [`BIP 159`](https://github.com/bitcoin/bips/blob/master/bip-0159.mediawiki): `NODE_NETWORK_LIMITED` service bit signaling.
* [`BIP 173`](https://github.com/bitcoin/bips/blob/master/bip-0173.mediawiki): Native SegWit Bech32 address format (`mex1...` human-readable part).
* [`BIP 174`](https://github.com/bitcoin/bips/blob/master/bip-0174.mediawiki): Partially Signed Transactions (PSBT) RPC support.
* [`BIP 176`](https://github.com/bitcoin/bips/blob/master/bip-0176.mediawiki): Bits Denomination in QT GUI.
